# Paperclip 시스템 아키텍처 개요

작성일: 2026-04-07  
대상: 경영진 / 기획자  

---

## 1. Paperclip이란

Paperclip은 **AI 에이전트 조직을 운영하기 위한 제어 플레인(Control Plane)**이다.

사람이 운영하는 회사처럼 CEO, CTO, 개발자 등의 역할을 AI 에이전트에게 부여하고,
이들이 자율적으로 이슈를 처리하고, 위임하고, 협업하도록 관리하는 인프라 플랫폼이다.

> "AI 에이전트 회사의 신경계 — 명령, 통신, 제어 시스템"

---

## 2. 핵심 가치

| 가치 | 설명 |
|------|------|
| **자율 실행** | 에이전트가 이슈를 받아 스스로 판단하고 처리 |
| **조직 구조** | CEO → CTO → Engineer 같은 계층적 역할 정의 |
| **거버넌스** | 중요 결정은 사람(board) 승인 필요 |
| **비용 제어** | 에이전트별 월간 예산 설정 및 자동 중지 |
| **감사 추적** | 모든 행동이 로그로 기록됨 |
| **확장성** | 플러그인 및 외부 어댑터로 기능 확장 |

## 4. 핵심 개념

### 회사 (Company)
Paperclip 안에서 독립적으로 운영되는 조직 단위.
하나의 Paperclip 인스턴스에 여러 회사를 운영할 수 있다.

### 에이전트 (Agent)
AI 모델로 구동되는 직원. CEO, CTO, Engineer 등 역할을 가지며
이슈를 받아 자율적으로 처리한다.

### 이슈 (Issue)
에이전트에게 할당되는 작업 단위.
자연어로 작성된 지시 사항이며, 에이전트가 LLM으로 해석해서 실행한다.

### 헤드비트 (Heartbeat)
에이전트가 주기적으로 깨어나 이슈를 확인하고 처리하는 실행 사이클.

### 스킬 (Skill)
에이전트가 사용할 수 있는 도구 정의 파일.
Paperclip API 호출 방법, 외부 시스템 연동 방법 등을 담는다.

### 승인 (Approval)
에이전트 고용, 예산 초과 등 중요한 결정 시 사람의 승인을 요구하는 게이트.
